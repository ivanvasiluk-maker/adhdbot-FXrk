## Коммерческая логика

После первого явно полезного применения — короткое приглашение без цены. Содержание результата, вопрос и попытка остаются прежними. `substantive=True` не заменяет факт пользы. Более полное автоматическое предложение требует двух отдельных полезных применений в журнале; показ или выполнение с неизвестным эффектом не подходят. Старые счётчики не обходят журнал.

Все автоматические экраны группы, включая прямой путь после третьего дня и завершение программы, проверяют общую защиту. Кризис, safety, заявка, пауза, ухудшение, последняя неудачная попытка, STOP, явно отмеченное напряжение или отсутствие сил блокируют предложение. Последнее неблагоприятное состояние сохраняет запрет до нового отчёта, это намеренно консервативно. Неизвестный эффект не превращается в пользу. Ручной просмотр условий остаётся отдельным выбором пользователя и не считается автоматическим показом.

Предел — один автоматический показ в местный календарный день; прежний семидневный предел основного оффера сохраняется. «Не сейчас», самостоятельное продолжение и отказ сохраняют `offer_declined_at` и семь дней подавления, включая перезагрузку. Первое приглашение также записывает время показа. Цены показываются при открытии условий, из общего конфига: группа €240, личная работа от €99/месяц. Бесплатный бот не превращается в платный.

## Показатели

`python scripts/product_metrics.py --db /absolute/path/to/bot.db --through 2026-10-06`

Подключение SQLite строго read-only; QA-пользователи исключаются. Экспорт содержит только агрегаты. В числителях не дублируются user/action. Будущие и некорректные даты исключаются. Нулевой знаменатель даёт `null`, а не нулевую успешность.

| Показатель | Наблюдаемое значение | Ограничение |
|---|---|---|
| Activation | Доля пользователей с показанным/отчитанным конкретным действием | Полезный разбор без действия здесь не измеряется |
| Skill adoption | Доля отчитавшихся, явно применивших способ полностью или частично | Не требует повторения и не утверждает пользу |
| Independent use | Доля отчитавшихся, явно применивших без подсказки | Самостоятельность не выводится из посещения |
| Generalisation | Доля отчитавшихся с полезным применением одного способа в двух известных контекстах | Более строгий критерий, чем простое использование |
| Behaviour change | Подтверждённое продолжение дела среди попыток с известным продолжением | Наблюдаемый сигнал, не причинный эффект и не изменение относительно baseline |
| Model accuracy | Доля явно подтверждённых сопоставленных гипотез | Нужны ответы человека; выполнение упражнения их не заменяет |
| Memory value | Доля явно подтверждённых релевантных воспоминаний | Без оценок человека неизвестно |
| Retention | Возвращение с отчётом в разные местные даты | Не D7 retention и не доказательство причины возвращения |

Для двух оценок доступны явные данные пилота: `--assessments /path/to/judgements.json`. Формат: объект с массивами `model_accuracy` и `memory_value`; запись содержит `user_id`, уникальный `assessment_id`, `calendar_date`, булево `confirmed`. Не включать свободный текст. Будущие, недатированные и чужие оценки исключаются. Сам бот эти суждения автоматически не придумывает.

`core.product_metrics.text_reduction(before, after)` сравнивает число набранных символов в одних и тех же непустых сценариях. Названия кнопок и голос не входят в ручной текст. Для отчёта нужны сопоставимые реальные прогоны. Снижение на 70% не заявлено: исходных замеров нет.

## Решение о выпуске

Техническая ветка предназначена для проверки PR. Перед коммерческим выпуском остаются реальные прогоны Telegram, подтверждение доставки заявок и пилот с 5–10 тестировщиками. Проверить неоднозначные ситуации, точность гипотез, память, один реалистичный шаг, понятное завершение и самостоятельность. Критерии 67–68 должны подтвердить люди через несколько дней, а не счётчик тестов.

Пять точек продажи: первый успех даёт мягкое приглашение; несколько результатов — персональный экран; карта доступна для ручного просмотра; открытый недельный итог предшествует необязательному автоматическому предложению с общей защитой. Повторяющаяся точка обсуждается только в подтверждённой пользователем цепочке с тремя выполненными пробами без продолжения дела в разных датах. Число проб проверяется по исходным записям; отказанные гипотезы и ухудшение не подходят. Такой вывод не объявляет человека неспособным работать самостоятельно и не означает клиническую необходимость терапии. Полная продуктовая приёмка требует живых проверок.
