## Проверка и публикация

Команды приёмки PATCH-43:

```sh
python -m unittest discover -s tests -p 'test_dialogue_ux_patch.py'
python scripts/regression_gate.py
```

Результат локальной проверки 2026-09-30: 330 unit/integration-тестов прошли; полный regression_gate прошёл, включая сценарные smoke-проверки, проверку 386 карточек и запуск с BOT_STARTUP_CHECK без Telegram polling и без OpenAI. Живые API этим не проверены.

Тесты проверяют сохранение вопроса после перезапуска, голосовой ввод, отсутствие выдуманных фактов, привязку к задаче, ответы своими словами, отрицания, выбор формы обращения, приоритет безопасности и расчёт наблюдаемых результатов. Ожидания существующих текстовых тестов обновлены под новые подписи; проверки поведения сохранены.

aiogram обновлён с 3.4.1 до 3.13.1: код уже импортирует DefaultBotProperties, отсутствующий в прежней закреплённой версии. Проверить запуск с реальными Telegram/OpenAI настройками на тестовом боте перед переносом на основной.

Локальная копия получена снимком исходников, поэтому локальная проверка истории коммитов не заменяет CI с настоящей историей. Ветка публикации создаётся от настоящего main, с сохранением всех остальных файлов дерева.

## Что остаётся до заявления «полный аудит закрыт»

1. Пройти живым Telegram-клиентом ввод, возврат после паузы, кризисный путь, старые inline-кнопки, платежи и фоновые напоминания.
2. Довести все старые прямые отправки до общего слоя диалога; проверить каждую форму обращения и все карточки навыков.
3. Проверить дедупликацию накопленного опыта и роли исторических ответов.
4. Измерить удержание после выкладки: возврат на второй/седьмой день, долю завершённых попыток после ошибки или уточнения. Рост удержания пока не измерен.

Этот патч — проверяемое улучшение основных путей, а не подтверждение полного исполнения всех P0/P1/P2 или выкладки в работающего бота.
