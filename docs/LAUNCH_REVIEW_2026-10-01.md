# PATCH-44: решение о первом запуске SKILLER Bot

Дата: 1 октября 2026. Репозиторий: ivanvasiluk-maker/adhdbot-FXrk.
Ветка: codex/skiller-dialogue-ux-20260930. PR: #139.

## Решение

После короткой проверки на тестовом Telegram-боте — запускать небольшой набор пользователей. Первая денежная модель: бесплатная помощь с конкретным делом, затем добровольная запись на группу или личные встречи с Иваном. Подписку на самого бота пока не включать: её ценность, удержание и расходы на обслуживание ещё не измерены. Это оценка продукта и кода, не доказательство эффективности помощи или доходности.

| Взгляд | Вывод | Что важно при запуске |
| --- | --- | --- |
| Психологический | Бот пригоден для проверки коротких действий и обсуждения результата. | Называть предположение версией; не приписывать эмоции; давать возможность остановиться; не обещать лечение или постоянное человеческое сопровождение. |
| Маркетинговый | Продавать понятную помощь с делом, которое человек откладывает. | Сначала полезная попытка, затем конкретная группа/личная работа. Одна заявка, один контакт. Дата начала и условия группы должны быть реальными. |
| Инвестиционный | Есть основание проверить спрос небольшой группой пользователей, но нет доказанной экономики. | Измерять возврат, выполненные попытки, полученные заявки, состоявшиеся встречи и оплаты. Пока не расширять набор функций и не тратить крупную сумму на рекламу. |

Рекомендация начать с небольшого числа пользователей и личного общения с ними соответствует общему подходу Y Combinator: https://www.ycombinator.com/blog/ycs-essential-startup-advice/ . Решение о готовности именно этого бота основано на проверке его кода, а не на этой статье.

## Что исправлено во втором проходе

- Добавлены шесть сочетаний обращения: «ты/вы» × мужской/женский/нейтральный род. Выбор добровольный; по умолчанию — нейтральное «вы». Команда /address доступна из /settings. Пол по имени не определяется.
- Настройка применяется на общем уровне отправки: обычные ответы, ответы на кнопки, изменения сообщения и подписи к фото. Изменение настройки сохраняет текущий вопрос и возвращает его на экран.
- Сохранены исходные слова пользователя в кавычках, ссылки, команды и идентификаторы кнопок. Подписи ключевых кнопок сделаны нейтральными; обработчики старых кнопок сохраняются.
- Основной запрос к модели получает сохранённое обращение. Для старых шаблонов используется явный словарь проверенных форм, без попытки угадать русскую грамматику по окончанию слова.
- Убраны английские названия режимов и несколько сложных терминов из общих экранов; сокращены представления тренеров и тексты помощи.
- Убраны обещания «результат будет», «не уйдёшь», автоматического освоения навыков, постоянного сопровождения и неподтверждённой скорости результата. Удалены выдуманные скидочные дедлайны в старых шаблонах.
- Итог первой попытки больше не придумывает цикл «напряжение → избегание → облегчение» и прогноз момента следующей трудности.
- Новые пользователи получают напоминания после выбора, а не по умолчанию. Сохранён выбор существующих пользователей. Пауза блокирует возвратное напоминание, ограничения частоты не увеличены.
- Стоимость группы в основных предложениях берётся из настроек. Ошибка пересылки заявки больше не выдаётся за успешную доставку.

## Примеры проверяемых форм

| Настройка | Пример |
| --- | --- |
| Ты, мужской род | Ты уже попробовал. Готов? Открой файл и напиши одну строку. |
| Ты, женский род | Ты уже попробовала. Готова? Открой файл и напиши одну строку. |
| Ты, нейтрально | Уже получилось попробовать. Можно попробовать? Открой файл и напиши одну строку. |
| Вы, любой род | Вы уже попробовали. Готовы? Откройте файл и напишите одну строку. |

Это примеры грамматики, не универсальное упражнение: для уборки, письма, звонка и других дел выбирается соответствующее действие.

## Проверка кода

Полный `python scripts/regression_gate.py` прошёл локально: 342 основных теста, дополнительные сценарные проверки, 386 карточек навыков и запуск с BOT_STARTUP_CHECK. Сеть Telegram/OpenAI при этом не использовалась. Проверку GitHub нужно оценивать по последнему коммиту PR, а не по первому проходу.

## Что не доказано и не завершено

1. Реальные Telegram/OpenAI-запросы, доставка заявки Ивану и работа на производственной базе не проверялись из этой среды. Проверки ниже обязательны перед приглашением людей.
2. Это не полный редактор русского языка: редкая новая фраза, текст, созданный моделью, или сообщение с явно заданными Telegram entities может потребовать правки. Явные entities оставляются без изменения, чтобы не ломать позиции форматирования. Цитаты пользователя намеренно не переписываются.
3. Подробные старые отчёты и неактивные карточки требуют дальнейшего сокращения. Старые выводы в истории не пересчитаны. Дедупликация всех исторических источников остаётся отдельной задачей.
4. Рост удержания, готовность платить за бота и прибыль пока не измерены. Запуск сам по себе не гарантирует доход.

## Минимальная проверка перед приглашением пользователей

Использовать отдельного тестового бота и отдельную базу. Секреты хранить вне Git. Нельзя запускать второй процесс с токеном работающего бота.

1. Пройти /start, выбрать женский род и «ты», описать бытовую задачу. Получить действие, попросить объяснить, ответить голосом и своими словами, закончить попытку.
2. Через /address выбрать «вы». Проверить, что предыдущий вопрос сохранён. Перезапустить тестового бота и проверить сохранённую настройку.
3. Отправить пустое голосовое: бот должен предложить повторить или написать текстом. Убедиться, что результат не записан как выполненная попытка.
4. Проверить отказ от напоминаний и /stop. Сообщение о риске для себя должно открывать помощь по безопасности раньше обычного задания или продажи.
5. Пройти выбор группы/личной работы, отправить собственную тестовую заявку и проверить её получение у Ивана. Проверить прямую ссылку на контакт и бесплатный выход.

Текущие значения по умолчанию: группа €240 за 8 встреч, личная работа €200/месяц. Это значения кода, не подтверждение действующего прайса. До набора сверить их с фактическими условиями, назвать дату начала группы и доступное время для ответов. Изменение цен — через настройки, без новой разработки.

Для первого запуска оставить FREE_BETA_ACCESS=true, TEST_MODE=false, PAYMENT_ACCEPT_ANY=false. Платежи за самого бота не включать. Флаг SKILLER_ACTION_ROUTER_ENABLED по умолчанию выключен; не переключать одновременно с выкладкой без отдельного прохождения маршрута. Общий слой языка и настроек работает и со старым маршрутом.

После проверки — действовать по docs/PRELAUNCH_DEPLOY.md: просмотр PR, перенос проверенного изменения в main, резервная копия базы, проверка запуска и перезапуск службы. Пример резервной копии при уже настроенном DB_PATH:

```sh
python scripts/backup_sqlite.py "$DB_PATH"
BOT_STARTUP_CHECK=1 python bot.py
```

## Первые две недели

Начать с небольшого набора, например 20–30 заинтересованных пользователей. Это предложение для проверки, не норматив рынка. Раз в несколько дней смотреть: сколько описали задачу, выполнили действие, вернулись, оставили заявку, дошли до встречи и оплатили. Отдельно учитывать время Ивана на поддержку и расходы на сервисы. Первой продавать существующую группу с понятной датой и программой; не обещать безлимитную личную переписку. Решение о расширении принимать по этим данным.
