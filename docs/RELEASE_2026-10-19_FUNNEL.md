# PATCH-74: консультация и бесплатное продолжение

Сверено с main PATCH-73 и экспортом переписки 14–19 октября. Сохранены короткий/подробный разбор, объяснённый выбор навыка, группа, индивидуальный тренинг, подбор коллеги по согласованию, заявки с квитанциями, карта/история/тренеры, добровольное продолжение после закрытия дня. Оплата за бот не вводится.

После завершённой попытки с отмеченным продолжением дела можно показать одно мягкое приглашение, без требования закрыть день. Проверки фактического результата, незавершённого упражнения, ухудшения, кризиса, повторного показа и отказа сохраняются. В режиме срочной ситуативной помощи приглашение не показывается. Приглашение не меняет текущую задачу/экран и имеет бесплатный выход. Отказ подавляет последующие автоматические предложения на семь дней; ручной вход в поддержку остаётся доступным.

Ссылка Cal.com передана владельцем и используется без добавления истории или данных клиента. Доступна в приглашении и в карточке индивидуальной помощи. Состав месячного пакета €99 не определён — эта цена больше не показывается в текущем предложении. Стоимость/условия консультации согласуются до начала. Настройки цены группы сохранены; даты старта не добавляются. Личный тренинг и запрос на подбор коллеги остаются через форму в боте. Старые выключенные платёжные режимы не удаляются и не включаются.

Коммерческий экран содержит краткое наблюдение о результате и варианты поддержки. Подробная карта и план доступны отдельно. Продолжение дела не выдаётся за доказанную эффективность навыка. Добавлено восстановление названия из текущего разбора при отсутствии рабочего заголовка. Выбор между делами теперь показывает названные пользователем варианты кнопками.

Обращение применяется на границе исходящих сообщений с сохранением цитат/URL. Исправлены возврат к ReplyKeyboardRemove из коммерческого окна, реальный выход «Продолжить задачу самому», состояние и текст меню после двух попыток. Добровольный шаг учитывает ограничения выбора навыка.

Автоматические тесты проверяют одно полезное действие → приглашение → индивидуальный формат/Cal.com → форма → квитанция тестовой отправки → бесплатный возврат с тем же делом. Доставка в Telegram/email подменена транспортом в тестах. Прямой переход по URL не считается заявкой/бронированием; фактическая запись в Cal.com и живое получение заявки владельцем не подтверждены. Ссылка не открылась через публичный инструмент чтения, поэтому расписание и стоимость не предполагаются.

Проверка после деплоя: /health PATCH-74, новая попытка, один добровольный переход в поддержку, запись/заявка по выбору владельца, получение и возврат к тренировке. Не отправлять реальные тестовые записи в календарь без отдельной задачи.
