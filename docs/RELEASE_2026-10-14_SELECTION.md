# PATCH-69: ограничения и отрицания в подборе навыков

Кандидат подготовлен в `codex/skill-selection-fixes-20261014` на основе main PATCH-68. Деплой выполняет владелец; main не обновляется в ходе подготовки этой ветки.

Альтернативные названия навыков нормализуются до проверки исключений. Все пути запасного подбора сохраняют запреты, ограничение повторений и отсутствие подтверждённого механизма. При исчерпании подходящих вариантов возвращается отсутствие результата, а пользователь видит предложение паузы/уточнения без новой карточки и попытки; задача и предыдущие результаты сохраняются.

Для самокритики и отвлечений явные отрицания не считаются положительным сигналом. Отрицание в последней обратной связи отменяет старую категорию; смешанные сообщения с положительным сигналом и «не могу перестать себя ругать» сохраняют возможность подбора. Это ограниченный детерминированный разбор сообщений, а не универсальное понимание русского языка.

Новые регрессии проверяют отрицания, старую категорию, положительные/смешанные сообщения, обход через alias, исчерпание вариантов, явный повтор и пользовательский путь без новой попытки.

Бот остаётся бесплатной воронкой. Ключ OpenAI сохраняется существующий. Письма требуют LEAD_EMAIL_TO=Ivan.vasiluk@gmail.com, LEAD_EMAIL_FROM и RESEND_API_KEY на сервере. Реальная отправка и живые ответы OpenAI в локальных проверках не подтверждаются. `/health` после выпуска должен показать PATCH-69 и выбранный SHA.

Локальные проверки завершены: 695 тестов основной серии, обязательные регрессии, состояния, кнопки, карта, сохранение, продуктовые ограничения, 386 карточек и запуск без polling. Старый сценарий проверки обычного продолжения перенесён на свежего пользователя: предыдущие сценарии намеренно исчерпывали историю навыков. Отдельная новая регрессия проверяет отсутствие новой попытки при исчерпании вариантов. Проверка GitHub CI фиксируется в PR.
