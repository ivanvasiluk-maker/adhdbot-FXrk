NO-GO означает наличие дефекта или недостаток обязательного подтверждения; эти два основания ниже разделены. Новая продуктовая функциональность для запуска не предлагается.

## Архитектура и сценарии

`scripts/start_bot.sh` выполняет preflight, затем `run_bot.py` подключает admin router и запускает `bot.main`. `bot.py` содержит около 18,7 тыс. строк: маршрутизацию, экран безопасности, обучение, предложения, фоновые задачи. `flows.py`, `texts.py`, `skills.py` обеспечивают разбор и карточки. `core/` содержит новые модели эксперимента, уточнения случая, выбор навыка, доставку заявок и аналитику. SQLite обслуживается через `db.py` с добавочными миграциями; есть legacy/cohort-разделение (`core/product_config.py`). Общедоступного web API это описание не предполагает: внешние границы — Telegram update/callback, OpenAI, Sheets, Telegram/email доставки заявки.

## Приёмка владельцем: один сценарий на телефоне

Использовать отдельного staging Telegram-бота с отдельной БД; production bot token не копировать в локальный polling. Владелец сообщает только build marker/SHA и результат, без секретов и реальных клиентских историй.

1. `/version` или `/health`: сверить версию с согласованным staging SHA. `/start`, выбрать тренера, прочитать согласие.
2. Ввести синтетический эпизод: «Хочу написать отчёт. Перед началом боюсь ошибки, открываю видео и на минуту чувствую облегчение». Проверить, что гипотеза отделена от сообщённых фактов.
3. Пройти один выбранный навык; отметить реальный результат и продолжение дела. Проверить сохранение после закрытия/открытия Telegram.
4. Добровольно открыть группу: сверить условия; отправить «ТЕСТ ПРИЁМКИ, НЕ РЕАЛЬНАЯ ЗАЯВКА». Владелец подтверждает, что получил именно эту заявку; бот показывает квитанцию, а не покупку.
5. Вернуться к тренировке, убедиться, что задача сохранилась. Не проводить оплату.
6. В отдельном тестовом профиле проверить safety: явная опасная фраза должна остановить обычный сценарий и предложение группы. Проверить выход только через предусмотренный триаж; не считать совпадение по ключевому слову клинической оценкой.
7. `/reset_me`, затем `/start`: локальный профиль должен быть новым. Владелец отдельно удаляет тестовую доставленную заявку из внешних каналов согласно runbook.
